# 高空高度课程与当前成功判定

更新：2026-10-12。

## 文献与实现范围

参考文献：**Autonomous Landing on a Moving Platform Using Vision-Based Deep Reinforcement Learning**，Pawel Ladosz 等，IEEE RA-L，2024，DOI：10.1109/LRA.2024.3379837。

当前为 CPU / PyBullet 中的辅助视觉 DrQ-v2 实验，含模仿标签、动作平滑、RGB中心估计及近地辅助控制。随机B样条运动参考PerchRL思路。这里新增的高空课程、辅助高分辨率视觉与停止门槛均为本项目设置，不能写成原论文已复现的结果。

## 当前 SUCCESS 是什么

代码见 `landing_repro/environment.py` 的 `fully_inside()`、`_event()` 与 `soft_landing` 计算。

1. 无人机与平台发生真实物理接触。
2. 至少一个接触点属于平台顶面：接触法向的z分量大于0.5，平台接触点高度不低于已知顶面高度减0.03米。
3. 无人机机身及全部部件的世界轴对齐包围盒水平四角，转换到平台坐标后，都落在1×1米平台的边界内；每边留0.0001米数值余量。这是保守的包围盒检查。

满足即记 `success` 并终止回合；接触但不满足则记 `platform_edge`。中心估计是否可用不直接决定success，目标中心误差也没有额外独立阈值。成功判定沿用之前口径。

**软着陆**还要求：接触前水平相对速度不超过0.2米/秒、竖直相对速度绝对值不超过0.18米/秒，接触时横滚和俯仰角绝对值均不超过10度。

当前没有检查首次接触后的持续停稳、反弹或滑出；因此success表示首次接触位置合格。软着陆比例以所有验证尝试为分母，不以成功次数为分母。

## 高度计划

高度相对平台顶面：1.5（保留低级回顾）→2→2.5→3→3.5→4→5→6→8→10→12→15米，每级扰动±0.3米。当前按用户指令从3.5米继续，平台保持较缓随机B样条，速度0.1–0.4米/秒、加速度上限0.15米/秒²。

每5000训练步冻结网络验证20次。当前同一平台难度、同一高度连续3轮：每轮成功率至少80%、软着陆比例至少60%，三轮成功率最大差不超过5个百分点，才升级。当前累计步数上限600000；若15米阶段通过可提前停止，预算用尽仍未通过则停止并保存，不代表已经收敛或达到15米能力。

## 高空感知与时限

原84×84画面中标识在高空过小。3米起，仅辅助RGB中心估计器增加按自身高度选择的图像分辨率；网络仍接收3×84×84，保持已有权重兼容。最大辅助分辨率随阶段增加，15米级上限924×924，实际下降时自动减小。分辨率改变时重建二维光流缓存，保留三维滤波状态。

分辨率选择使用无人机自身高度与已知平台平面高度，不读取目标实时中心作为控制输入。平台实时真值仍用于训练标签、奖励及评估指标。额外渲染会增加CPU耗时；这改变了感知条件，不能当作原始固定相机分辨率的严格单因素高度实验。

单回合时限为`max(60, ceil((名义高度+0.3)/0.25+20))`秒；10、12、15米分别62、70、82秒。公式中的0.25米/秒是分配时限的参考值，不是强制下降速度。
