# 近平台丢失中心后的末段完成与下降速度

日期：2026-10-11。

文献：**Autonomous Landing on a Moving Platform Using Vision-Based Deep Reinforcement Learning**，Pawel Ladosz 等，IEEE RA-L 2024，DOI：10.1109/LRA.2024.3379837。

本页记录本仓库增加的辅助控制改进，不是论文原算法或纯 DrQ-v2 的复现成绩。

## 1. 第 66 回合为什么没有继续下降

原日志：`runs/smooth_near_20261011_141534/train_episode_0066.csv`，事件 `NEAR_ESTIMATE_LOST`。

结束时，真实水平误差约 0.040 米，机体参考点比平台表面高约 0.037 米。网络仍给出向下速度请求，但中心估计超时，辅助控制器把下降指令置零，最终触发估计丢失终止。

这些真实距离仅用于事后诊断。参考点高度不等于起落架间隙，也不能直接证明已满足真实接触条件；控制器不会读取真实平台中心。

## 2. 下降速度是谁决定的

远处，网络输出归一化动作，映射成三维速度请求，竖直请求范围为 ±0.5 m/s，再经过指令平滑和底层飞控。

近距离，辅助控制器会依据估计误差、相对速度、倾角和置信度限制下降。因此现在看到的速度是**网络请求与人工控制规则共同作用**的结果。

| 阶段 | 原版近距离辅助 | 本次开启末段辅助后 |
| --- | --- | --- |
| 近距离接近 | 下降指令上限 0.08–0.12 m/s | 提高到 0.12–0.24 m/s，越靠近越低 |
| 最后完成接触 | 仍依赖普通预测下降门槛 | 条件满足后，控制器给定 0.10 m/s 向下目标 |
| 中心完全失效且未进入末段 | 停止下降 | 继续保持原有停止下降规则 |

数值是控制指令，不保证瞬时实际速度。原有加速度、jerk 和指令变化限制仍保留。最后的 0.10 m/s 是控制器设定，不能称为模型自己学出的速度。

## 3. 有时限的末段完成

新增可选参数 `--terminal-finish-assist`，要求同时启用预测与近距离辅助。默认环境配置仍关闭，以保留旧实验行为；桌面启动脚本启用它。

每回合最多进入一次，需要在进入时同时满足：

- 已进入近距离辅助，且仍有有效的观测或普通预测中心；不能从完全未知状态直接进入。
- 相对估计平台表面的参考点高度大于 0.02 米且不超过 0.22 米。
- 到估计中心的水平距离不超过 0.16 米，相对水平速度不超过 0.12 m/s。
- roll/pitch 各不超过 12°；置信度至少 0.12，水平位置标准差不超过 0.30 米。
- 网络已请求下降，竖直请求小于 −0.02 m/s。

进入后暂存当时的估计中心和水平速度，继续外推平台位置，维持小幅横向修正，以 0.10 m/s 的目标速度完成下降。即使普通中心估计随后失效，也不会立即停止下降。

该阶段最长 **4 秒**。距离偏离超过 0.30 米、相对水平速度超过 0.35 m/s、倾角超过 20°、高度回升超过 0.35 米或网络明显请求上升时退出。没有实际接触且超过时限，记为 `terminal_timeout`，不会记成成功。

普通估计失效期间，中心标记注明 **FINISH COAST**。它是短期保留的推测位置，置信度按 `进入时置信度 × exp(-末段时间 / 2)` 衰减；不是新的视觉检测，也不是经校准的概率。每次有效观测的普通中心显示保持原标签。

## 4. 已做的检查

实现检查：[terminal_finish_checks.json](results/terminal_finish_checks.json)。包括从有效估计进入、随后完全漏检仍继续下降、未知/未对准时不进入、4 秒终止，以及 PyBullet 中必须实际接触才能成功。没有调用优化器。

冻结网络对照：[terminal_policy_frozen_comparison.json](results/terminal_policy_frozen_comparison.json)。同一份累计 17013 步的模型、相同 6 个初始种子；仅改变辅助控制配置：

| 指标 | 旧近距离辅助 | 加快接近 + 末段完成 |
| --- | --- | --- |
| 成功 / 软着陆 | 5/6，5/6 | 6/6，6/6 |
| 平均回合时长 | 11.91 秒 | 8.56 秒 |
| 平均飞行 jerk RMS | 4.02 m/s³ | 4.48 m/s³ |

时长包含失败回合，不等于只统计成功飞行的平均时间。加快后 jerk 增加，速度与平滑性仍需权衡。该测试包括与故障相关的开发种子，不是第 66 回合逐帧重放，也不是独立测试集的统计结论；网络权重测试前后校验一致，优化更新为零。

## 5. 训练恢复方式和局限

修改前已安全中断并保存累计 **17013** 步的 `interrupted.pt`。桌面脚本自动从最近中断检查点恢复，使用新的输出目录：

```bash
bash start_smooth_training.sh
```

权重、优化器和累计计数保留；经验缓存、随机数状态和部分回合重置，不是完全相同状态的接续。辅助控制配置改变后，独立验证排名重置，旧最佳模型保留为历史版本。活动目录以 `runs/current_smooth_training.txt` 为准。

当前只验证低速平台、固定难度的少量场景。末段平台突变运动会使恒速预测失准；辅助控制成功不能算成纯神经网络成功，训练累计成功数也不能当作新配置的独立评估成功率。
