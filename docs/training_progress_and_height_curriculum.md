# 无人机移动平台降落：训练成果与高度课程

更新日期：2026-10-12。

## 1. 研究来源与当前实现

参考文献：**Autonomous Landing on a Moving Platform Using Vision-Based Deep Reinforcement Learning**，Pawel Ladosz 等，IEEE Robotics and Automation Letters，2024，DOI：10.1109/LRA.2024.3379837。

当前实现运行在 CPU / Ubuntu 20.04 WSL2 / PyBullet 中，使用真实 Crazyflie 动力学、机载图像、DrQ-v2 网络、辅助模仿学习、动作平滑约束、视觉中心估计及近地辅助控制。它是参考论文任务建立的辅助视觉学习系统，尚不能表述为原论文全部实验或纯 DrQ-v2 的完整复现。随机 B 样条运动参考了此前讨论的 PerchRL 思路，未复现 PerchRL 的完整训练体系。

## 2. 同一模型的本次冻结测试

采用历史上曲线验证较好的 **155000 步模型**：`runs/height_setup_20261012_160318/selected_best.pt`。每个难度测试20次，共80次；网络输出均值动作，关闭探索噪声，不更新网络参数。每个难度固定种子范围，测试数据与模型 SHA256 记录在 `results/frozen_difficulty_assessment_20261012.json`。

| 难度 | 平台运动及速度 | 初始高度（平台上方） | 成功次数 / 成功率 | 软着陆次数 / 比例 | 成功回合平均水平误差 |
| --- | --- | --- | --- | --- | --- |
| 0 | 匀速直线；每回合速度在0–0.3 m/s抽取 | 1.5±0.3 m | 20/20，100% | 20/20，100% | 3.44 cm |

| 2 | 较缓随机 B 样条；0.1–0.4 m/s | 1.5±0.3 m | 13/20，65% | 13/20，65% | 16.65 cm |
| 3 | 更快随机 B 样条；0.1–0.5 m/s | 2.5±0.5 m | 0/20，0% | 0/20，0% | 无成功回合 |

难度3是未经该难度训练的迁移测试，同时提高了平台速度、转向和初始高度，不能把下降归因于其中某一个因素。这里的“软着陆比例”分母是全部20次尝试。平均误差只统计成功回合；不能用它代表全部回合。

失败分布：难度2有6次近地中心估计失效、1次平台边缘接触；难度3有16次近地中心估计失效、4次普通视野丢失。当前的主要瓶颈是曲线运动下的视觉跟踪和预测持续性。

这80次使用固定验证种子，且每项仅20次，是小样本操作验证，不是独立测试集上的泛化能力结论；100%不能理解成任何条件下必然成功。

## 3. 历史训练进展与口径

旧日志记录如下，来自不同训练时刻及部分不同辅助控制版本，不能拼成“当前同一个模型在所有难度上的成绩”：

| 历史任务 | 较好记录 | 最近相关记录 |
| --- | --- | --- |
| 匀速直线 | 20/20（100%） | 40000步，20/20 |
| 变速直线 | 95000步，19/20（95%） | 切换曲线前125000步，16/20（80%） |
| 较缓随机曲线 | 155000步，17/20（85%），软着陆16/20 | 175000步，13/20（65%） |
| 更快随机曲线 | 尚无正式训练后的验证 | 本次仅做迁移测试，0/20 |

本次排查发现，旧界面的 `update_center_marker()` 会在显示刷新时再次调用估计器，对同一帧重复更新。界面刷新频率因此可能影响估计和控制，这使旧 GUI 验证与独立无界面重测不能直接等同。已经修正为仅显示 `_observe()` 计算出的中心估计。历史17/20保留为旧日志记录，当前可复核的曲线基线以本次13/20为准。

已经通过两份真实仿真的对照检查：其中一份执行90次额外中心显示刷新和6次三视图渲染，另一份不执行这些刷新；30步内估计、图像、物理状态、奖励与终止条件保持一致。该检查验证了显示过程的隔离，不代表提高了模型成功率。

175000步旧模型完整保留在 `runs/motion_curriculum_20261012_120231/`。新的高度课程从历史选出的155000步权重分支继续，步数因此回到155000附近，不表示175000步模型丢失。优化器随检查点加载，经验池、随机数状态和未完成回合重新初始化，不是精确恢复整个训练现场。累计训练成功次数跨越多个难度，且分支回合编号有继承，不能除以界面总回合数当作当前难度成功率。

## 4. 已启用的高度课程

当前先尝试 **2.0±0.3 m**，平台保持难度2随机曲线，速度0.1–0.4 m/s、加速度上限0.15 m/s²、转向速度上限10°/s。横向出生范围保持±0.65 m，近地中心追踪、预测奖励、动作平滑与末端辅助仍启用。

高度均指**相对平台顶面的高度**，不是相对世界地面的高度。依次为：

**2.0 → 2.5 → 3.0 → 4.0 → 5.0 → 6.0 → 8.0 → 10.0 → 12.0 → 15.0 m**，每级随机扰动±0.3 m。

- 每5000个训练步冻结网络验证20回合，不使用探索噪声。
- 当前同一平台难度、同一高度连续3轮验证：每轮成功率≥80%，软着陆比例≥60%，三轮成功率最大差≤5个百分点，才允许升高。
- 未满足条件，保持当前高度继续训练；不会按训练步数强行升高。
- 每5次训练回合中1次使用上一级较低高度，平台运动保持相同，减少遗忘；正式验证不混入较低高度。
- 提高高度时保存该级完成模型和最佳模型，并清空旧经验池及半个回合，避免跨任务拼接。
- 低高度单回合时限为60秒；10、12、15米分别为62、70、82秒。3米起加入按自身高度调整分辨率的辅助RGB检测，网络仍接收84×84图像。时限及感知配置有变化，不能视为只改变高度的严格单因素对照。
- 当前训练累计步数预算600000，作为计算上限；满足15米阶段条件可提前结束。该门槛是实用停止条件，不能证明数学意义上的收敛，也不保证在预算内学会15米降落。

11级初始高度和8种升级/拒绝升级条件均已检查。3–15米的24次静态初始化均检测到标识，另检查了3次分辨率切换。这些是环境及相机检查，不是训练成功率；暂不宣称10米以上已训练成功。详见[高空高度课程](high_altitude_curriculum.md)。

## 5. 保存与启动

旧曲线模型：`runs/motion_curriculum_20261012_120231/`，`latest.pt`为175000步，`best.pt`为155000步。

正在运行的目录可查：`runs/current_smooth_training.txt`。每1000步保存`latest.pt`；正常停止或中断会保存进度。`best.pt`在当前高度首次正式验证后产生；跨级后保存`best_height_*.pt`及`height_*_completed.pt`。

桌面入口：**继续提高高度训练.cmd**。运行时保留原来的 **UAV LANDING TRAINING** 和 **Bullet Physics** 两个窗口。已有训练窗口开着时，入口不会启动第二份训练。暂停请用面板的Pause；结束并保存请用Stop and save model。
