### 真实复现障碍：奖励公式和参数表歧义

1. 式(9)排版为`ds-dxy/ds`，字面计算可在零误差得到极大的水平奖励；同时保留`(ds-dxy)/ds`的归一化解释。
2. 式(8)用指令速度判断是否超限，却将实际速度放进指数。真实随机飞行中已观察到回合回报约`8.01e26`。字面版本已保存停止，结果不是学习成功。
3. 继续运行的独立实验显式采用`--vertical-reward actual_guard`，对实际下降速度超过安全限值的情况给惩罚。此项是有界语义解释，尚未确认等同作者代码；它不修改实际执行动作，不接入辅助控制。
4. Table I写有“automatic entropy tuning=yes”，但标准DrQ-v2为确定性策略，没有对应温度目标；未擅自添加SAC温度损失。
5. Fig.3为BatchNorm，官方通用DrQ-v2为LayerNorm；本次选择Fig.3并记录目标网络统计量更新方式。
6. 相机参数、底层控制器精确增益、选用的400张DTD纹理和实拍平台图片不完整。当前无域随机化基线使用合成H标志，不能声称复现了论文的域随机化sim-to-real设置。
7. 式(7)是否在接触时覆盖LOS门控未知，当前保留外层门控。成功碰撞使用现有保守包围盒和顶面接触检查，原文未详细给出接触几何实现。

因此当前标签为“独立论文实验/已记录解释版本”，不能标为逐项等同作者实现。作者需要回答的问题另见`author_reproduction_questions.md`。

脚本默认按论文4000回合训练，并设3.6M步上限；只有完成训练的种子才执行最终评估。前10000步是随机预热，优化更新数为0属正常。CPU计算耗时可能很长，目前没有论文规模成绩。
