# 参考 PerchRL 的随机移动平台与后续课程训练

日期：2026-10-11。

## 文献与借鉴范围

参考文献：[**PerchRL: Vision-Based Agile Perching on Inclined Platforms under Rapid and Irregular Motion**，arXiv:2606.03441v3](https://arxiv.org/html/2606.03441v3)，III-B 的 Platform Motion 部分、公式 (1)–(4)。其平台参考运动采用随机闭合三次 B 样条、曲率检查和相关速度扰动。

当前工程的主体仍是 Ladosz 等人的 **Autonomous Landing on a Moving Platform Using Vision-Based Deep Reinforcement Learning** 的 CPU 辅助训练改编。本次只借鉴 PerchRL 的平台运动生成思想，没有复现它的 TCN、CTBR 动作、倾斜栖停或完整训练流程。

## 实现方式

代码：`landing_repro/platform_motion.py`。

1. 每回合按种子产生 12 个极坐标控制点；对半径做环形平滑，形成周期均匀三次 B 样条。
2. 解析计算曲线一阶、二阶导数，密集检查曲率。必要时二分收缩半径偏差。
3. 按弧长前进；同一位置的切向决定平台运动方向和平台朝向。平台保持水平，不加入倾斜。
4. 使用 OU 相关扰动产生速度目标，并额外施加速度、加速度和加速度变化限制，防止跳变。
5. 每个物理步移动平台，同时同步碰撞体的位置、朝向和线/角速度。接触判定使用当时的平台朝向，相对接触速度使用实际仿真平台速度。

为适配当前任务，本实现增加了几个约束：曲率按**速度上限**检查，并分配法向加速度预算；半径随运动限制设置，以保留余量；速度目标经过额外平滑和限幅。这些参数是本工程的选择，不是论文的精确参数。曲率属于密集采样检查，不是连续域形式化证明。

随机样条不等于逐帧随机位置。曲线的闭合接缝在位置、一阶和二阶导数上连续；每回合曲线、速度变化和初始方向可以不同。平台只有运动环境生成器知道未来曲线，策略和视觉预测器不会读取轨迹表或未来点。

## 后续难度安排

代码：`landing_repro/motion_curriculum.py`。

| 运动阶段 | 运动方式 | 速度范围 | 加速度上限 | 转弯速率上限 | 初始高度，相对平台 |
| --- | --- | --- | --- | --- | --- |
| 0 | 当前的匀速直线 | 0–0.30 m/s | 无主动变速 | 不转弯 | 1.2–1.8 m |
| 1 | 平滑随机变速直线 | 0.08–0.35 m/s | 0.10 m/s² | 不转弯 | 1.2–1.8 m |
| 2 | 缓弯随机 B 样条 + 变速 | 0.10–0.40 m/s | 0.15 m/s² | 10°/s | 1.2–1.8 m |
| 3 | 更快的随机 B 样条 + 变速 | 0.10–0.50 m/s | 0.25 m/s² | 20°/s | 2.0–3.0 m |

上限不表示每回合都会达到该数值。阶段 3 同时把 X/Y 初始偏移范围从各 ±0.65 m 扩大到各 ±1 m。

每累计 5000 个交互步，在当前阶段的固定种子上独立测试 20 回合。连续三轮均满足成功率至少 80%、软着陆率至少 60%，且三轮成功率最大差不超过 5 个百分点，才升一级。各阶段使用不同的固定验证种子；验证期间没有探索噪声和参数更新。

升级后重置验证排名和在线经验缓存，保存上一阶段完成模型与最佳模型。后续训练每 5 回合有 1 回合重访前一阶段，离线示范也保留；验证始终使用当前目标阶段，不混入简单回合抬高分数。达到最后阶段的稳定条件才按性能目标停止，否则最多新增 80000 个交互步。

这些门槛是工程规则，不能证明数学收敛；反复使用的验证种子属于开发验证，正式汇报还需另留未用于调参的测试集。

## 漏检时的预测如何处理

当前视觉估计器仍是**线性匀速 Kalman 滤波**，没有升级成 PerchRL 的转弯模型 EKF。变速/曲线阶段依据配置的加速度上限提高预测过程噪声，使预测不确定度更快增大。这只改变先验，不读取真实平台加速度。

同时缩短末段保留时间，避免转弯时长时间盲目沿直线推测：

| 阶段 | 末段进入高度上限 | 最长完成时间 |
| --- | --- | --- |
| 0 | 0.22 m | 4.0 s |
| 1 | 0.10 m | 1.2 s |
| 2 | 0.09 m | 1.0 s |
| 3 | 0.08 m | 0.8 s |

高度是机体参考点相对估计平台表面的高度。沿用低相对速度、对准、低倾角和最低置信度等进入条件；末段下降目标仍为 0.10 m/s。较短时限会更保守，可能增加失败，需要在后续训练中验证，不能预先保证成功。

## 如何启动后续训练

**当前桌面训练继续使用匀速 Stage 1，本次没有中断它。新的课程不会自动替换已运行的进程。** 当前一轮结束并关闭训练窗口后，在已经安装好的 WSL 环境中执行：

```bash
cd /mnt/d/paper_reproductions/posture_control
bash start_variable_motion_training.sh
```

脚本从最近一轮的 `latest.pt` 恢复；若存在中断检查点则优先使用 `interrupted.pt`。如已有训练或完成窗口仍在运行，会拒绝重复启动。默认从阶段 0 验证起步；恢复已有课程检查点则继承保存的运动阶段。权重和优化器保留，经验缓存、随机数和部分回合不做完全一致恢复。

该脚本立即启动后续训练，不会在后台等待当前任务结束。活动目录仍写入 `runs/current_smooth_training.txt`。桌面状态显示运动阶段和平台实时速度，CSV 增加平台速度和朝向，便于事后分析。

手动复查（不训练）：

```bash
conda activate landing-drqv2
python -m landing_repro.check_platform_motion
python -m landing_repro.checks
```

## 界面里的 return

`return=13.48` 表示该回合每一步实际奖励相加后是 13.48 分，不是成功率、误差或损失。奖励包括接近、预测引导、平滑与相对速度项，以及终止事件奖励。先看 `SUCCESS` / 失败状态，再结合接触误差、速度和 jerk。不同阶段、奖励规则或辅助控制配置下，不能只靠 return 横向比较。
