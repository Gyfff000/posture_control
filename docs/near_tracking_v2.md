# 变速平台近距离中心丢失：局部视觉跟踪与末段衔接

日期：2026-10-11。关联文献：**Autonomous Landing on a Moving Platform Using Vision-Based Deep Reinforcement Learning**，Pawel Ladosz 等，IEEE RA-L 2024，DOI 10.1109/LRA.2024.3379837。

本次是本仓库的辅助估计与控制改进，属于视觉网络与规则控制器的混合方法，不能作为论文纯 DrQ-v2 的复现结果。

## 1. 为什么接近平台却不下降

故障记录：`runs/motion_curriculum_20261011_195010/train_episode_0268.csv`。结束时，机体参考点高于平台表面约 **0.099 m**，真实水平误差约 **0.036 m**。网络归一化竖直动作仍为 **−0.201**，执行动作却变成 **0**。原因是中心估计失效后，近距离控制器禁止下降。

旧变速阶段仅在估计高度不超过 0.10 m 时才能进入最后下降。PnP 估计的表面高度与实际表面可能相差几厘米，预测还会因加速度不确定性提前失效，两个条件之间因此出现衔接空档。真实平台位置只用于上述事后诊断，不供控制器读取。

## 2. 本次改动

### 标识不完整时，继续使用局部图像信息

完整标识被识别后，在标识内部保存图像特征及其中心像素。接近平台后，即使外边框离开视野，也尝试通过相邻图像的光流和单应矩阵传播中心，再结合无人机自身姿态、位置以及先前估计的平台平面换算世界位置。

只有前后向光流一致、至少 6 个有效特征、空间分布非退化、RANSAC 内点比例达到 75%、几何变换合理且通过滤波器创新检查，才接受该局部更新。局部观测噪声比完整标识更大。

- 完整检测显示 `VISION`，局部跟踪显示 `PARTIAL FLOW`，纯外推显示 `NEAR PREDICTED`。
- 局部跟踪仍归入 `predicted`，不会冒充完整检测，也不会因此解锁只允许完整观测时收集的教师训练标签。
- 日志新增 `partial_flow_used`，与旧的“还有标识像素时进行预测”指标区分。
- 完整标识的漏检计时不会被局部跟踪重置。置信度仍随时间和估计不确定性衰减；局部跟踪失败后也会超时。
- 不读取平台真值、分割 ID 或未来轨迹。

### 提前衔接最后下降，并检查不确定性

| 运动阶段 | 旧入口高度 | 新入口高度 | 新末段最长时间 | 新末段向下目标速度 |
| --- | --- | --- | --- | --- |
| 变速直线 | 0.10 m | 0.24 m | 2.4 s | 0.14 m/s |
| 温和随机 B 样条 | 0.09 m | 0.20 m | 2.0 s | 0.14 m/s |
| 更快随机 B 样条 | 0.08 m | 0.17 m | 1.6 s | 0.14 m/s |

仍要求已经进入近距离辅助、有有效估计、水平偏差不超过 0.16 m、相对水平速度不超过 0.12 m/s、倾角不超过 12°、置信度至少 0.12、网络请求下降。未知位置不能直接进入。

增加几何误差预算：水平偏差 + 位置标准差 + 速度标准差 × 外推时间 + 0.5 × 配置加速度上限 × 外推时间²。预算超过 0.40 m 时不进入或退出最后下降；该指标是启发式几何预算，不是经过校准的概率保证。还要求剩余下降能在时限内完成。

进入后，如果收到新的完整或局部视觉更新，可修正暂存中心和平台速度；普通匀速外推不能重置盲飞计时。距离、速度、倾角、上升请求和超时退出条件继续生效。只有实际物理接触才记为降落成功。

## 3. 验证结果

先保存 **80000 步**检查点，再冻结相同网络，对比修改前后各 6 个相同种子。无探索噪声，无优化更新，检查点 SHA256 测试前后一致。

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| 成功降落 | 2/6 | 5/6 |
| 软着陆 | 2/6 | 5/6 |
| `near_estimate_lost` | 4/6 | 1/6 |
| 被接受的局部光流更新帧 | 0 | 252 |

本轮 6 次新配置测试中，末段完成控制器没有实际触发，改善主要来自局部视觉更新让普通近距离控制继续工作。提前末段衔接另外通过了估计丢失后的物理接触检查。不能将这 6 次的改善全部归因于提前末段控制。

原先成功的种子 90001 在新配置中失败，说明仍存在局部跟踪和预测误差；它最终参考点距平台约 0.21 m、水平偏差约 0.21 m，长期缺少有效观测后停止下降。不能声称问题已在所有轨迹下解决，更不能用 5/6 代表独立测试集成功率。种子包含与训练故障相关的开发场景，不是带探索噪声的原回合逐帧重放。随机 B 样条两阶段的新增入口参数尚未进行冻结模型性能对比。

详细记录：[冻结对照](results/near_tracking_v2_comparison.json)、[局部跟踪与物理检查](results/near_tracking_v2_checks.json)。检查覆盖标识被裁切、空白画面拒绝、局部更新不重置完整检测年龄、预测超时、过大不确定性不进入末段、有效视觉更新修正末段、估计失效后必须实际接触。

## 4. 使用和复查

桌面仍使用“继续变速平台训练.cmd”。本次从保存的 80000 步模型继续阶段 1，保留原总步数上限 145000；新控制器版本会清空旧验证排名，再按原门槛验证及升级难度。训练动作仍由网络与探索噪声提出，再由辅助控制器约束；不是纯网络控制。

```bash
conda activate landing-drqv2
cd /mnt/d/paper_reproductions/posture_control
python -m landing_repro.check_near_tracking
python -m landing_repro.check_terminal_finish
python -m landing_repro.check_near_landing
```

本机旧代码备份在 `runs/near_tracking_fix_baseline/`。带该备份和兼容检查点可复查冻结对照：

```bash
python -m landing_repro.check_near_tracking_policy \
  --checkpoint runs/motion_curriculum_20261011_195010/interrupted.pt \
  --baseline runs/near_tracking_fix_baseline \
  --output runs/near_tracking_v2_recheck
```

其他机器需要自行准备旧版本的 `center_marker.py`、`near_landing.py` 与训练检查点；模型及本机旧代码备份不上传 GitHub。恢复会继承权重、优化器和累计计数，重新创建经验回放及当前回合，不是逐状态精确续训。
